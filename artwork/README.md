# Arcane Client artwork

`arcane-client-icon.png` is the full-resolution source for the emblem. The packaged 256×256 asset is located at `src/main/resources/assets/arcaneclient/icon.png`.

The emblem was generated with OpenAI's built-in image generation tool using this design brief:

> Original Arcane Client emblem: a bold angular capital A implied by a glowing arcane rune, encircled by one broken orbit ring and a small four-point spark. Clean, vector-friendly, centered, and readable at 128×128. Deep near-black indigo background, luminous violet rune, cyan edge highlights, crisp silhouette; no wordmark, watermark, Minecraft imagery, weapons, or visual clutter.

The old placeholder icon from the supplied binary is preserved at `legacy/artifacts/donuttrace-icon.png`.
