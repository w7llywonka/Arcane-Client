02 / THE PIPELINE

A smaller search.
A stronger answer.

The scanner spends time where growth actually exists, then combines shape, stage, and change over time. The result is cleaner evidence with less work per loaded chunk.

  1. 01

    Palette skip

    Chunk sections with no growth-relevant block states are rejected before a block-by-block pass begins.

    LESS WORLD WORK
  2. 02

    Pattern read

    Rows, rectangles, farmland support, crop stages, mature density, sapling layouts, and vertical columns.

    STATIC GEOMETRY
  3. 03

    Live delta

    Two focused packet hooks watch actual growth advances and harvest/reset cycles without broad event noise.

    TEMPORAL PROOF
  4. 04

    Explain & mark

    Evidence becomes a reasoned score, chunk tile, radar mark, current-chunk readout, or growth-site label.

    AUDITABLE OUTPUT

03 / THE TOOLKIT

One focused scanner.
A complete field kit.

DISCOVERYCORE

Growth scanner

Finds crop rows and rectangles, synchronized and mature crops, organized saplings, sugar-cane and cactus columns, non-native plant clusters, plus observed growth and harvest cycles.

  • Sensitivity 0–100
  • Radius 2–24
  • Per-dimension history
  • Manual rescan
WORLD INTELVISUAL

Chunk awareness

Chunk tiles, compact radar HUD, current-chunk evidence, tracers, labels, diagnostics, and alert history.

ESPINDEPENDENT

07 / INSTALL

Drop in.
Read the field.

Arcane Client runs entirely on the Fabric client. No account, license key, or external service is required.

MINECRAFT 1.21.11 JAVA 21 FABRIC LOADER 0.19.3+
Get Arcane Client ↗ Report an issue
  1. 01
    Install Fabric

    Use Fabric Loader for Minecraft 1.21.11 and add a compatible Fabric API.

  2. 02
    Add the JAR

    Place Arcane Client in the Minecraft mods folder.

  3. 03
    Open the GUI

    Launch the Fabric profile and press Right Shift.

BUILD FROM SOURCE.\gradlew.bat clean build
