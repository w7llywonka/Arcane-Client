Performance

Choose how much time Arcane can use.

Profiles change budgets, refresh cadence, render limits, and fill detail without reducing scanner accuracy.

Profile Scan budget Refresh Storage Items World targets
High FPS Default 1.00 ms/tick 20 ticks 256 128 384
Balanced 1.85 ms/tick 10 ticks 512 256 768
Quality 2.50 ms/tick 5 ticks 1,024 512 1,500

Opening the Click GUI pauses the HUD and 3D overlays and caps background scanning at 0.5 ms/tick. Actual FPS depends on hardware, shaders, resource packs, and the loaded world.

Install

Ready in three steps.

Arcane Client is a standard client-side Fabric mod. No account, license key, or external service is required.

Minecraft 1.21.11 Java 21 Fabric Loader 0.19.3+ Fabric API 0.141.6+
Get Arcane Client
  1. 1
    Install Fabric

    Set up Fabric Loader and Fabric API for Minecraft 1.21.11.

  2. 2
    Add the mod

    Place the Arcane Client JAR in your Minecraft mods folder.

  3. 3
    Open Arcane

    Launch the Fabric profile and press Right Shift.

Build from source.\gradlew.bat clean build
