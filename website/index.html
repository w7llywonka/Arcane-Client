Clear answers

Frequently asked questions.

What creates a possible base lead?

Activity from selected growth states—including crops, saplings, sugar cane, and cactus—can create a lead. Repeated stage changes and harvest activity strengthen it.

Do storage blocks or light affect the score?

No. Storage, block entities, machines, placed-block density, interactions, and light have zero base-finding weight. The finder uses tracked growth activity.

What do the ESP tools do?

Storage, Item, and Tunnel ESP are independent visual tools. They can help you inspect an area, but they never create or strengthen a base lead.

Which Minecraft version is supported?

Arcane 2.3.5 targets Minecraft 1.21.11 with Fabric and runs entirely on the client.

How do I open Arcane?

Press Right Shift after launching the game. Keybinds can be changed from the client interface.

What is different about Premium?

Premium is the future growth-tracking tier and is still in development. The current Base client already includes the growth-based base finder, intel views, visual ESP tools, and player utilities listed above.
