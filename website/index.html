GET STARTED

Minecraft Java Edition · Fabric 1.21.11 or 26.3

Download v2.9.3 ↓
  1. 01

    Install Fabric

    Choose the matching Arcane download. Use Java 21+ for Minecraft 1.21.11, or Java 25+ for Minecraft 26.3.

  2. 02

    Add ARCLoader

    Import ARCLoader.jar into Modrinth or Prism, or place it in your Fabric mods folder. Keep the matching Fabric API installed. For Arcane, only the loader JAR belongs in mods—do not add a loose Arcane Client JAR.

  3. 03

    Launch Arcane

    Start Minecraft with Fabric. Arcane loads on the first launch; press Right Shift to open it. A future signed update may ask for one restart.
