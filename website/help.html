DOWNLOAD HELP

Get a code.
Get Arcane.

Download codes come from the official Arcane bot in Discord. The bot reply is private, expires after 10 minutes, and works once.

Join the Discord ↗

THREE STEPS

From Discord to download.

  1. 01

    Join the official server

    Use the Discord link above. Codes from other servers are not official Arcane codes.

  2. 02

    Run /code

    Type /code, choose the command from Arcane Code Generator, then send it. The bot shows your code in a message only you can see.

  3. 03

    Paste the full code

    Copy every group and hyphen. Return to the download window, choose the Minecraft version that matches your instance, paste it into Download code, and choose Unlock download, then choose Download ARCLoader. Import ARCLoader.jar into Modrinth or Prism, or place it in a normal Fabric mods folder. It is the only Arcane JAR that belongs there—do not add a loose Arcane Client JAR. Use Java 21+ for Minecraft 1.21.11 or Java 25+ for Minecraft 26.3. Arcane is already included and works on the first Fabric launch; a future signed update may ask for one restart.
